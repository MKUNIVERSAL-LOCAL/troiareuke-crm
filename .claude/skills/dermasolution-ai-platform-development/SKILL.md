# AI 플랫폼 개발

## 서비스 구조(16~24절)
- 이용 방식: AI 사용 안 함 / 내 API 키 연결(BYOK, 1순위) / 내 AI 계정 연결(BYOA — 공식 지원·제휴 확인 시에만) / DERMASOLUTION AI(Managed, 본사 공식 API). 미제공 방식은 "준비 중" 또는 Feature Flag 로 숨김. 사용자 동의 없는 유료 전환·동일 요청 이중 청구·장애 시 타 유료 제공사 자동 전환 금지.
- 정확한 수치는 CRM 내부 분석 엔진이 계산, AI 는 해석·원인·행동 제안. 추천에는 근거·사용 데이터·기간·불확실성 표시. 예상 매출을 확정처럼 표시 금지. AI 추천 동작(발송·예약 변경·결제·환불·데이터 변경)은 관리자 승인 없이 자동 실행 금지. AI 장애·오프라인에서도 CRM 기능은 정상.

## 어댑터 인터페이스(17절) — 비코어 `src/lib/ai/`
제공사 선택·모델 선택·인증 검증·연결 테스트·텍스트/스트리밍/구조화 JSON 응답·시스템 프롬프트·이미지 지원 여부·토큰 사용량·예상 비용·요청 제한·오류·재시도·응답 시간·모델별 기능·한도. 모델 이름·가격·기능은 하드코딩하지 않고 **변경 가능한 모델 카탈로그**(서버/Feature Flag 로 원격 갱신)로. 기존 `src/lib/aiProxy.ts`(본사 중계)·AiChat 호출은 어댑터 뒤로 점진 통합하고 기존 동작을 깨지 않는다.

## 키·인증 보안(21절)
API 키를 GitHub·노션·로그·오류 리포트·IndexedDB·localStorage·엑셀·백업·렌더러·모바일 번들·exe·프런트 env 에 평문 저장 금지. 현재 `ai_key_*` localStorage 보관은 **이전 대상**(승인 대기열 D-13): Electron safeStorage/OS 키체인, 모바일 보안 저장소, 또는 동의·암호화·정책 검토를 통과한 서버 측 보관. 본사 마스터 키를 지점 프로그램·앱에 전달 금지. 키 마스킹·교체·삭제·연결 해제·요청량·비용 한도·감사로그·로그 민감정보 제거. `backupSanitize` 가 키를 제외하는지 테스트로 고정.

## 개인정보(22절)
기본 요청에 고객 실명·전화·주소·이메일·생년월일·사진·민감 상담·결제수단·DB 원본 미전송. 내부 가명 ID(`aiAlias.ts`)와 집계 통계만. 사진·민감 상담 분석은 별도 동의·처리 근거·제공사 데이터 정책·보안 검토 뒤. 매장 간 데이터 격리는 서버가 검증. 의료 진단·치료 효과 확정 표현 금지.

## 설정 마법사(18~19절)
설정 → AI 서비스: 제공사·모델 선택, 키 등록/변경/삭제, 연결 테스트, 상태·마지막 확인 시각, 월 사용량·예상 비용(제공사 청구와 다를 수 있음 표시), 한도·알림·차단. 단계별 한국어 안내 + 공식 링크(OpenAI platform api-keys/billing/pricing, Anthropic console, Google AI Studio apikey/billing), 오류 해결(키 오류·크레딧 부족·네트워크), FAQ, 개인 구독(ChatGPT Plus 등)과 API 요금은 별개임을 명시. 안내의 확인일·출처 관리. 미연결 상태에서 AI 가 되는 것처럼 표시 금지.

## 본사 Gateway·Router·크레딧(25~28절, PHASE 5)
기존 NAS 서버 구조와 호환되게 모듈화(처음부터 서버 추가 금지). 매장 인증·구독 확인·모델 라우팅(업무 난이도별 저비용/표준/고성능)·사용량·토큰·비용·중복 요청·동시 비용·한도·실패/재시도·장애·개인정보 필터·프롬프트 버전·품질·감사로그. 크레딧 차감은 서버 정본, 중복 차감·환불 잔액 오류 방지. 요금제 가격은 가설(원가 실측 뒤 오너 확정). 본사는 사용량·비용 통계만, 대화 내용·고객 PII 열람 기능 금지.

## 금지(20절)
사용자 AI 계정 비밀번호 수집, 세션·쿠키 탈취, 비공식 API, 구독 계정 공유, 로그인 세션 자동화, 사용 제한 우회, 계정 재판매.

## 테스트(37절 AI)
정상 키·잘못된 키·변경/삭제·평문 저장 방지·백업/로그 비밀정보 검사·매장별 격리·전환·미연결·크레딧 부족·모델 불가·네트워크 실패·타임아웃·한도·중복 차감·구독 만료·권한 없음·PII 필터·프롬프트 인젝션·대량 요청·AI 장애 시 CRM 정상. 실비용 테스트는 승인된 테스트 키·제한 예산으로만, 실고객 데이터 금지.
