# 네이버 예약 연동 제휴 신청 가이드 + 제안서 초안 (2026-09-07)

## 1. 어디에, 어떻게 신청하나 (조사 결과)

- 네이버 예약(스마트플레이스) API는 공개 API가 아니다. 뷰티 CRM(헤어짱 등)은 네이버와 제휴해 "예약 연동 프로그램"으로 등록되어 있고, 매장은 스마트플레이스에서 그 프로그램을 골라 연결한다(네이버 고객센터 문서 "예약-헤어짱 연동 방법": 연동 조건 = 예약 서비스 개설 관리자 아이디, 예약 서비스 유형 **뷰티형(헤어샵·네일샵·에스테틱샵)**, 다른 프로그램에 미연결).
- 솔루션사가 그 목록에 들어가는 공개 신청 폼은 따로 없다. **공식 창구는 네이버(주) "제휴 제안"** 이다.
  - 등록: https://www.navercorp.com/naver/proposalRegister
  - 절차 안내: https://www.navercorp.com/naver/proposalGuide
  - 검토 현황 조회: https://www.navercorp.com/company/partnerStatus (등록번호 + 이메일)
- 절차: ① 등록·접수(완료 메일) → ② 담당자 검토, 필요 시 추가 자료 요청 → ③ 결과 통보. **기본 5일 이내 처리**, 주요 사안은 더 걸림. 추가 자료 요청에 **30일 내 미회신이면 종료**. 담당자 면담을 전제로 쓰지 말 것. 영업비밀은 쓰지 말고 공개 가능한 내용만.
- 폼 항목: 제휴 희망 영역(**기술·API** 선택 권장) / 세부 영역 / 제목 / 제안서 첨부(PDF·PPT·HWP 등, 50MB) / 내용 / 구분(기업) / 회사명 / 제안자명 / 전화 / 이메일 / 홈페이지 / 회사 소개서 첨부.
- 보조 창구: 스마트플레이스 사업주 고객센터 1:1 문의(아르케스파 계정으로 "외부 고객관리 프로그램 예약 연동 등록 절차" 질의)를 병행하면 담당 부서 안내를 받을 수 있다.

- [ ] 사업자등록증(트로이아르케/MK) 사본, 회사 소개서 1~2쪽(PDF)
- [ ] 더마솔루션 서비스 소개서 3~5쪽(PDF): 화면 캡처(예약 관리·고객·자동 알림), 운영 지점 수(현재 2곳, 파일럿 아르케스파), 서버 구조(자체 NAS 중앙 서버·일일 백업), 개인정보 보호(동의 수집·마스킹·삭제 처리), 자동 업데이트
- [ ] 연동 설계 요약(아래 3절 그대로): 네이버 예약 → CRM 수신·상태 동기·중복 방지(naverBookingId), 취소·변경 반영, 노쇼 방지 알림
- [ ] 홈페이지 주소: https://crm-update.mkcorp.familyds.com/
- [ ] 아르케스파 스마트플레이스 계정 현황(예약 서비스 유형이 **뷰티형**인지 확인 — 아니면 네이버 예약 설정에서 유형 변경)

## 3. 제안서 본문 초안 (폼 "내용"에 그대로 붙이고, 첨부 PDF에도 동일 내용 + 화면 캡처)

제목: 에스테틱·피부관리 전문 CRM "더마솔루션"의 네이버 예약 연동(뷰티형) 제휴 제안

내용:

[제안 개요]
더마솔루션(DERMASOLUTION)은 피부관리실·에스테틱 전문 고객관리 프로그램입니다. 고객·예약·시술기록(전후 사진)·회원권·매출·손익·자동 재방문 알림을 하나로 관리하며, 본사 중앙 서버에 실시간 저장·일일 백업되는 구조로 현재 2개 지점이 운영 중이고 아르케스파에서 파일럿을 진행 중입니다. 매장의 네이버 예약을 프로그램에서 함께 관리할 수 있도록, 기존 뷰티 CRM들과 같은 방식의 "네이버 예약 연동 프로그램" 등록을 제안드립니다.

[제휴 희망 내용]
1. 네이버 예약(뷰티형) 예약 정보의 조회·수신(신규·변경·취소)과 예약 상태 반영을 위한 API 연동 권한
2. 매장이 스마트플레이스에서 "더마솔루션"을 연동 프로그램으로 선택할 수 있도록 등록
3. 연동 정책(예약 시간 설정 주체, 미노출 처리, 해제 시 데이터 처리)은 네이버 가이드를 그대로 따름

[연동 설계]
- 수신: 폴링 또는 웹훅으로 예약을 받아 CRM 예약과 네이버 예약 ID 기준으로 중복 없이 동기화
- 반영: 매장에서 완료·취소 처리 시 상태를 네이버에 반영(권한 범위 내)
- 노쇼 방지: 예약 확인·전일 리마인드 자동 알림(발송사 연동)과 재방문 리마인더
- 보안: API 자격증명은 본사 서버(NAS)에만 보관, 지점 PC에는 노출되지 않음. 고객 개인정보는 수집 동의·화면 마스킹·삭제 요청 처리 절차 운영

[회사·서비스 정보]
- 회사: (회사명) / 담당: (제안자명, 직책) / 연락처: (전화) / 이메일: (메일)
- 서비스 소개·다운로드: https://crm-update.mkcorp.familyds.com/
- 운영 현황: 지점 2곳(아르케스파, 박재영에스테틱), 본사 관리자 콘솔로 다지점 운영

[요청 사항]
연동 등록 절차와 필요 서류(사업자·서비스 심사 항목·개발 가이드)를 안내해 주시면 즉시 준비하겠습니다.

- 접수 완료 메일의 등록번호를 노션 데이터 저장소에 기록. 5영업일 뒤 검토 현황 조회.
- 추가 자료 요청은 30일 안에 회신(놓치면 종료). 회신은 개발자(Claude 세션)와 함께 작성.
- 승인되면 서버에 네이버 동기 워커 구현(설계는 docs/archive/미구현기능_점검_NAS연동_설계.md 5절) — 예약 데이터 매핑 코드(naverBookingId)는 이미 존재.
- 승인 전까지 매장 안내: 네이버 예약은 "예약 경로=네이버"로 수동 입력.
