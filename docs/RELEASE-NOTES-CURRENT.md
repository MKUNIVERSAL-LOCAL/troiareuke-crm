■ Before/After 사진 비교 — 고객에게 바로 보여주는 결과

• 고객 상세의 Before/After에서 비교할 두 사진을 직접 고르고, 각도별로 모아 보고, 경과일(D+N)을 확인할 수 있습니다

• 대시보드에 오늘 매출(결제수단·구분별)·환불·지출·시술·신규 고객·예약 결과(완료/노쇼/취소)가 모여 보이고, [복사]/[보내기]로 마감 보고 문구를 바로 보낼 수 있습니다

■ 내일 예약 안내
• 대시보드에 내일 예약이 모여 보이고, 고객별 [안내]로 예약 안내 문구 초안을 복사·공유할 수 있습니다 (전체 복사도 가능). 문자 발송사 연동 전에는 이 방법으로 노쇼를 줄이세요

■ 회차권 재구매 알림
• 대시보드에 잔여 1회 이하이거나 만료 14일 이내인 회차권 고객이 모여 보입니다. [재구매 안내]로 문구 초안을 복사·공유하고, 항목을 누르면 고객 상세가 바로 열립니다

■ 개인정보 보존기간
• 설정 > 알림 설정에서 보존기간(년)을 정하면 마지막 방문 후 그 기간이 지난 고객을 대시보드와 고객 화면 "보존기간 경과"에 모아 보여줍니다. 확인 후 [익명화]를 누르면 고객 정보와 예약·시술·결제·상담 기록의 이름·전화, 시술·상담 사진이 지워지고 방문·결제 통계는 남습니다. 익명화된 고객은 예약·발송·재방문 알림 대상에서 빠집니다 (자동 삭제 없음, 기본은 꺼짐)

■ 앱 잠금
• 설정 > 데이터 백업에서 PIN(숫자 4~6자리)을 켜면, 다른 앱·창으로 갔다가 돌아올 때 PIN을 물어 자리를 비운 사이 고객 정보가 보이지 않습니다 (기기별 설정, 기본 꺼짐, 잊으면 로그아웃으로 해제)

■ 모바일 앱
• 모바일에서도 고객을 바로 등록할 수 있습니다 (검색창 옆 + 버튼)
• 매출(결제·지출 내역)과 제품(목록·판매 기록) 화면이 모바일에서 표 대신 카드 목록으로 보입니다
• 모바일 고객 상세에 Before/After 비교와 최근 시술 기록이 함께 보입니다
• 설정 화면(샵 정보·영업시간)이 모바일에서도 입력란이 잘리지 않도록 정리되었습니다. 화면보다 긴 입력창(프로그램 추가 등)도 위가 잘리지 않고 스크롤됩니다
• 시술 기록에서 [카메라로 촬영]을 누르면 바로 카메라가 열려 시술 직후 사진을 붙일 수 있습니다. 시술 목록에 사진 장수가 표시됩니다
• [카메라로 촬영] 화면에 그 고객의 직전 시술 사진이 반투명으로 겹쳐 보여 같은 각도·거리로 찍을 수 있습니다 (투명도 조절, 가이드 사진 선택, 전/후면 전환). 촬영한 사진은 가이드와 같은 각도 태그를 자동으로 받습니다
• 사진 저장 공간이 크게 늘었습니다. 모바일 앱·PC 모두 사진을 기기의 대용량 저장소(IndexedDB)에 보관해 "용량 초과" 없이 수백 장을 담을 수 있고, 기존 사진은 첫 실행 때 자동으로 옮겨집니다
• 모바일 고객 상세에서 PC와 같은 작업을 할 수 있습니다: 피부 상담 기록·상담 이력, 시술 기록, 프로그램 등록, 고객 정보 수정. 예약 카드를 누르면 예약 상세(완료·취소·수정)가 열립니다
• 사진이 많아 기기 저장 공간이 찼을 때, 중앙 서버에 이미 저장된 사진의 로컬 복사본을 자동으로 비우고 계속 저장합니다 ("용량 초과"로 막히지 않음)

■ 안정성
• 화면 표시 중 오류가 나면 흰 화면 대신 안내와 [다시 시도] 버튼이 나옵니다. 저장된 데이터는 영향 없습니다
• 모든 팝업 창을 Esc 키로 닫을 수 있습니다

■ 개선·수정
• 대시보드 상단에 [고객 추가] [예약 추가] [시술 기록] 빠른 작업 버튼이 생겼습니다 (PC·모바일). 누르면 해당 화면의 등록 창이 바로 열립니다
• 전화번호를 숫자만 입력해도 자동으로 하이픈이 붙습니다 (고객·직원·가입·샵 전화)
• 고객·시술 검색에서 전화 뒷자리 4자리(하이픈 무시)나 초성(ㅌㅅㅌ)으로도 찾을 수 있습니다
• 시술 기록을 저장하면 결제도 바로 등록할지 묻고, 고객·금액·메모가 채워진 결제 창이 열립니다 (회차권 차감 시술은 제외)
• 고객 상세에 '다음 방문 권장'이 보입니다: 시술기록의 권장일 또는 마지막 방문+재방문 주기, 남은 일수(D-N)·지난 일수, 이미 잡힌 예약일
• 대시보드의 오늘 예약 항목을 누르면 예약 상세(완료·취소·수정)가 바로 열립니다
• 재방문 안내 초안과 메시지 발송 문구를 모바일에서는 [보내기]/[앱으로 보내기]로 카카오톡·문자 앱에 바로 넘길 수 있습니다 (PC는 복사)
• 설정 > 구독에서 무료 플랜 전환이 "서버에 구독 저장 실패"로 막히던 문제를 수정했습니다
• 본사 관리자 콘솔의 알림창을 지점 화면과 같은 토스트로 통일했습니다
• API 연동 가이드의 체크 항목 표기를 "확인 완료"로 바로잡았습니다 (실제 연동 상태가 아닌 자기 체크입니다)
