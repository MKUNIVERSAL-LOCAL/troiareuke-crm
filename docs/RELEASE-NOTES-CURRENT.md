v1.0.43 업데이트 내용

■ 안정성·정확성 대폭 개선 (전수 점검)
• 문자 발송 보호 — {고객명} 같은 변수가 남아 있는 메시지는 실수로 원문 그대로 발송되지 않도록 발송 전에 안내합니다
• 시술 기록 보호 — 기록 작성 중 고객을 바꿔도 이전 고객의 회차권에서 회차가 차감되지 않습니다
• 시술 기록에 시술일 입력 추가 — 지난 시술도 실제 날짜로 기록·수정할 수 있습니다
• 예약 수정 보호 — 여러 시술이 연결된 예약을 수정해도 나머지 시술이 사라지지 않습니다
• 새벽·아침 시간대(0~9시)에 대시보드·직원 현황의 "오늘/이번달" 집계가 어제 기준으로 표시되던 문제 수정
• 재방문 안내 권장일이 하루 어긋나던 문제 수정
• 직원 계정의 고객 엑셀 다운로드에도 화면과 동일한 전화번호 보호가 적용됩니다
• 엑셀 고객 업로드 시 전화번호 앞 0이 사라지거나 생년월일이 숫자로 저장되던 문제 수정
• 회원권 만료일이 등록한 날이 아닌 실제 구매일 기준으로 계산됩니다
• 제품 결제를 매출 화면에서 지우면 재고와 어긋나던 문제 — 제품/재고 화면의 판매 취소로 안내
• 업데이트 안내가 두 번 뜨거나 다운로드 후 예고 없이 재시작되던 문제 수정
• 그 외 입력 검증, 화면 표기, 오류 안내 등 40여 건 다듬음
