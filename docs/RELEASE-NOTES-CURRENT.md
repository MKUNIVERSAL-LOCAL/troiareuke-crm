■ 자동 업데이트 무인화 (전 지점)
• 새 버전이 나오면 프로그램이 스스로 내려받고, 프로그램을 닫을 때 자동으로 적용됩니다 — 이제 [지금 업데이트]를 누르지 않아도 항상 최신 버전이 유지됩니다
• 바로 적용하고 싶을 때는 [지금 재시작]을 누르면 됩니다
• 업데이트 적용이 더 안정적으로 바뀌었습니다 (백신 검사·파일 잠김 시 최대 2분 자동 재시도, 적용 결과 기록)
• 설치 파일을 다시 내려받으실 필요가 없습니다 — 기존 프로그램이 그대로 최신으로 바뀝니다

■ 본사 관리자 콘솔
• 지점별 프로그램 실행 버전을 대시보드·지점 관리·사용자 관리에서 확인할 수 있습니다 — 구버전으로 남은 지점이 바로 보입니다
• 신규 PC 설치 안내 주소·안내 문구 복사 버튼 추가 (기존 PC에는 보내지 않습니다)
