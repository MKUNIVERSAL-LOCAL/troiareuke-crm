v1.0.40 업데이트 내용

■ 새 기능
• 고객 등록 시 개인정보 수집·이용 동의 체크 추가 — 동의 일시가 고객 정보에 기록됩니다
• 예약 관리에 직원별 예약현황 추가 — 직원 필터와 직원별 건수 요약, 클릭으로 해당 직원만 보기
• 고객 정보에 티켓(프로그램) 차감 내역 표시 — 어떤 관리로 몇 회가 차감됐는지 티켓별로 확인
• 완료 처리 시 결제수단 선택 — 카드+현금 복합(분할) 결제 지원
• 결제수단 직접 추가 — '기타 추가'로 상품권 등 매장별 결제수단 등록

■ 개선
• 용어 변경: 마사지 → 바디관리
• 피부관리 전용 프로그램으로 정리 — 네일·속눈썹·반영구 등 무관 항목 제거
• 폴더형 설치(압축해제 방식)에서도 프로그램 안 업데이트 버튼으로 자동 업데이트 지원
