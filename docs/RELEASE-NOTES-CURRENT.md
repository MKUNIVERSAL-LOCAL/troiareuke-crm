■ 지점 가입 방식 변경 — 신청 후 본사 승인
• 새 지점은 프로그램에서 직접 가입 신청합니다. 샵명·연락처·사업자등록번호와 함께 사업자등록증 사진을 첨부하면 접수됩니다
• 본사가 서류를 확인한 뒤 승인하면 그때부터 로그인할 수 있습니다 (평일 기준 24시간 이내 처리). 거부된 경우 로그인 화면에 사유가 표시됩니다
• 이미 사용 중인 지점 계정은 그대로입니다. 다시 신청하거나 다시 로그인할 필요가 없습니다

■ 본사 관리자 콘솔
• 사용자 관리에 [승인 대기] 탭이 생겼습니다. 신청 내용과 사업자등록증을 확인하고 승인·거부(사유 입력)를 처리합니다
• 기존 계정 발급 기능은 그대로 유지됩니다

■ 기타
• 지점 데이터·화면에는 변경이 없습니다
