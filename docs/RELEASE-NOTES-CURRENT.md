v1.0.60 업데이트 내용

■ Before/After 사진 비교 — 고객에게 바로 보여주는 결과
• 시술 사진에 '시술 전/후'와 촬영 각도(정면·좌측·우측)를 표시할 수 있습니다. 기록의 첫 사진은 자동으로 '시술 전'으로 잡히고, 썸네일 아래에서 바꿀 수 있습니다
• 시술 기록을 추가할 때 같은 고객의 직전 사진이 참고로 함께 보입니다. 같은 각도·거리·조명으로 찍으면 비교가 정확해집니다
• 고객 상세의 Before/After에서 비교할 두 사진을 직접 고르고, 각도별로 모아 보고, 경과일(D+N)을 확인할 수 있습니다
• [이미지 저장]을 누르면 Before|After 비교 사진 한 장(샵 이름·날짜 포함)으로 만들어집니다. [복사]로 카카오톡 PC 대화창에 바로 붙여넣을 수 있습니다

■ 모바일 앱
• 모바일에서도 고객을 바로 등록할 수 있습니다 (검색창 옆 + 버튼)
• 매출(결제·지출 내역)과 제품(목록·판매 기록) 화면이 모바일에서 표 대신 카드 목록으로 보입니다

■ 개선·수정
• 설정 > 구독에서 무료 플랜 전환이 "서버에 구독 저장 실패"로 막히던 문제를 수정했습니다
• 본사 관리자 콘솔의 알림창을 지점 화면과 같은 토스트로 통일했습니다
• API 연동 가이드의 체크 항목 표기를 "확인 완료"로 바로잡았습니다 (실제 연동 상태가 아닌 자기 체크입니다)

■ 기타
• 저장된 사진·고객 데이터에는 변경이 없습니다. 프로그램을 닫고 다시 열면 자동으로 적용됩니다
