v1.0.58 업데이트 내용

■ 모바일 앱 준비 (Play 스토어·App Store 등록용)
• 같은 프로그램을 안드로이드·아이폰 앱으로 만들 수 있는 구조가 추가되었습니다. 스토어 등록이 끝나면 매장에서는 PC와 앱 어느 쪽으로도 같은 데이터를 봅니다
• 앱에서는 내보내기(엑셀·PDF)가 카카오톡·메일 등 공유로 전달되고, 외부 링크는 휴대폰 브라우저로 열립니다
• 앱은 새 버전이 나오면 화면 위에 안내가 표시되며, 앱 자체 교체는 스토어가 담당합니다
• 앞으로 모든 업데이트는 휴대폰 화면 폭에서도 핵심 화면이 깨지지 않는지 자동 검사를 통과해야만 배포됩니다

■ 배포 안정성
• 새 버전은 만들어지는 순간 본사 업데이트 서버에 바로 게시됩니다 (야간 자동 작업이 돌지 않아도 지점 프로그램은 다음 실행 때 최신으로 바뀝니다)

■ 기타
• PC 지점 프로그램의 화면·데이터에는 변경이 없습니다
