■ 백신 오탐 예방 (설치 후 1회)
• 설정 → 데이터 백업 탭에 [백신·보안 예외 등록] 카드가 생겼습니다 — 등록할 폴더 2개를 보여주고, 버튼 한 번으로 경로를 복사한 채 Windows 보안 예외 설정 화면을 바로 열어 줍니다
• 안랩 V3 사용 PC를 위한 메뉴 경로 안내 포함. 등록을 마치면 [등록을 마쳤습니다]로 이 PC에 완료 표시
• 프로그램 실행 파일에 제작사·설명·아이콘 정보를 채워 백신이 정상 프로그램으로 인식하기 쉽게 했습니다
