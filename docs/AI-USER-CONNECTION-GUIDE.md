# AI 연결 안내 (매장용) — 설정 > AI 서비스

갱신 2026-11-24 (151) · 화면: 설정 → **AI 서비스** 탭 · 관리자 계정만 키 등록·삭제 가능

## 1. 어떤 방식을 쓰나요?
| 방식 | 언제 | 비용 | 준비 |
|---|---|---|---|
| 본사 AI 중계 | 본사가 서버에 AI 키를 둔 매장 | 본사 정책(월 사용 한도) | 없음 — 켜져 있으면 바로 동작 |
| 내 키로 직접(BYOK) | 본사 중계가 없거나 내 계정으로 쓰고 싶을 때 | 제공사에 사용한 만큼(선불 크레딧/후불) | 아래 마법사대로 키 발급 → 붙여넣기 → 연결 테스트 |
| 본사 유료 AI | 준비 중 | 본사 크레딧 | — |
| 사용 안 함 | AI 기능을 쓰지 않음 | 0 | — |

우선순위: 본사 중계 → 내 키(Claude → ChatGPT → Gemini, 실패하면 다음 키). **AI 는 자료를 해석·추천만** 하고 숫자는 프로그램이 계산합니다.

## 2. 키 받기 (제공사별, 5분)
### ChatGPT(OpenAI)
1. https://platform.openai.com/ 로그인(ChatGPT 계정과 같아도 API 결제는 별도).
2. Settings → Billing 에서 결제 수단 등록 + 선불 크레딧(최소 $5 권장).
3. Dashboard → API keys → Create new secret key(이름: 더마솔루션).
4. `sk-` 로 시작하는 키 전체를 복사해 AI 서비스 탭 OpenAI 칸에 붙여넣고 [저장].
5. [연결 테스트] → "연결됨".

### Claude(Anthropic)
1. https://console.anthropic.com/ 가입·로그인 → Billing 에서 결제 수단·크레딧.
2. Settings → API Keys → Create Key → `sk-ant-` 키 복사 → Claude 칸에 붙여넣고 [저장].
3. **데스크톱 앱에서** [연결 테스트]. 브라우저·폰에서는 Claude 가 차단(CORS)되므로 OpenAI 나 Gemini 도 등록해 두면 어디서나 동작합니다.

### Gemini(Google)
1. https://aistudio.google.com/ Google 로그인 → Get API key → Create API key(무료 할당량 있음).
2. `AIza` 키 복사 → Gemini 칸에 붙여넣고 [저장] → [연결 테스트].

## 3. 모델 고르기
제공사마다 기본 모델이 정해져 있습니다(가성비). 더 좋은 모델을 고르면 답이 정교해지는 대신 토큰 단가가 오릅니다. 단가는 화면의 모델 목록에 참고값(USD / 100만 토큰)으로 표시됩니다.

## 4. 비용 감 잡기
- 질문 1건 = 자료(약 3,000 토큰) + 답(약 500 토큰). 기본 모델 기준 수 원~수십 원.
- 설정 탭 "이달 사용량"은 **이 기기에서 추정**한 값입니다. 정확한 청구는 제공사 콘솔이 정본입니다.

## 5. 보안
- 키는 이 PC(폰)의 앱 저장소에만 저장되고 본사·서버·백업 파일·AI 대화·로그에 들어가지 않습니다(운영체제 키 보관함 사용은 준비 중 — `AI-SECURITY-POLICY.md`).
- 전화번호는 가리고 고객 이름은 "고객#번호"로 바꿔 보냅니다. 직원 계정은 매출·직원 자료가 빠집니다.
- 키가 새어 나간 것 같으면 제공사 콘솔에서 키를 삭제(revoke)하고 새로 만든 뒤 다시 등록하세요.

## 6. 문제 해결
| 증상 | 확인 |
|---|---|
| 연결 실패(401/403) | 키 전체 복사 여부, 제공사 결제·크레딧 |
| 연결 실패(429) | 제공사 한도 초과 — 잠시 뒤 재시도, 한도 상향 |
| 브라우저에서 Claude 안 됨 | 정상(CORS) — 데스크톱 앱 또는 OpenAI/Gemini 키 |
| 답이 틀린 숫자를 말함 | 자료가 정본 — 화면 숫자를 확인하고 AI 답은 해석으로만 |
