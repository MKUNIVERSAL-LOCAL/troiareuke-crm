## 2. 실제 제공사 호출
- 자동 테스트는 **제공사를 호출하지 않는다**(비용·키 노출 방지 — 네트워크 가로채기). 실제 호출은 오너가 설정 > AI 서비스에서 키 등록 뒤 [연결 테스트]로 1회 확인한다(체크리스트 아래).
- Claude 는 데스크톱(Electron) 전용 — 브라우저·폰에서는 CORS 안내가 뜨는지 확인.

## 3. 오너 수동 체크리스트(아침)
1. 설정 → AI 서비스: 본인 OpenAI 또는 Gemini 키 등록 → [연결 테스트] "연결됨" → AI 챗 "📊 이달 경영 브리핑" 응답이 숫자를 자료 값 그대로 인용하는지(새 숫자를 만들면 D-3 2차에서 프롬프트 보강).
2. 직원 계정으로 같은 브리핑 → 매출 줄이 "[권한]"으로 빠지는지.
3. 백업(설정 > 백업·보안 > 지금 백업) 파일에 키 문자열이 없는지(키 꼴 검사 포함).

## 4. 남은 위험·보류
