## 1. 파일럿 시작 전 (본사, 30분)

- [ ] 어드민 대시보드: 아르케스파 프로그램 버전이 채널 최신과 같은가 (구버전 배지 없음)
- [ ] 어드민 > 전체 데이터 > 아르케스파 > 백업·복원 탭에 **오늘 날짜 일일 백업**이 있는가
- [ ] 어드민 > 사용자 관리: 아르케스파 계정(원장·직원) 역할·사용기간 확인, 불필요 계정 비활성
- [ ] 어드민 > 기능 관리: 아르케스파에 켜 줄 기능 확정 (AI 챗봇 ON 여부, 비컨 등)
- [ ] 서버 `.env` 결정 사항 반영 여부: `SMS_PROVIDER`(발송사 계약 시 solapi), `AI_OPENAI_API_KEY`(본사 AI 사용 시), `OPS_ALERT_EMAIL`
- [ ] 지점 PC: 설정 > 데이터 백업 > 백신·보안 예외 등록 완료 표시 / 설정 > 알림 설정 > 재방문 권장 주기 확인
- [ ] 지점 PC: 설정 > 결제수단 — 매장이 쓰는 결제수단 추가(서버 저장이라 한 PC에서만 하면 됨)

## 2. 첫 주에 지점이 실제로 할 흐름 (관찰 포인트)

1. 로그인 → 고객 등록(개인정보 동의 체크) → 엑셀 일괄 업로드가 필요한지
2. 예약 등록 → 당일 완료 처리 → 결제 등록(복합결제 포함) → 매출 화면 반영 확인
3. 시술 기록 + 사진 저장 → 다른 PC에서 같은 사진이 보이는지(NAS 동기)
4. 문자 발송 시도 → 발송사 미계약이면 "발송 안 됨(pending)" 표기가 이해되는지 (계약 후엔 실제 발송)
5. 재방문 리마인더 카드 → 대상 산출이 현장 감각과 맞는지, 주기 값 조정 필요 여부
6. 지출 등록·손익계산서 → 월말 세무 전달용으로 충분한지
7. 프로그램을 닫고 다시 켰을 때 업데이트가 조용히 적용되는지 (버전 표시 확인)

## 3. 매일/매주 본사가 볼 것

- 매일: 운영 경보 메일 수신함(백업 실패·예약발송 실패), 어드민 대시보드 최근 로그인(실패 사유)
- 매주(월 09:00 주간 점검 에이전트 리포트와 함께): 지점 프로그램 버전, 백업 날짜 수, 발송 로그(pending/failed 비율), AI 사용량(본사 키 사용 시)
- 문제 발생 시 순서: ① `docs/BRANCH-INSTALL-GUIDE.md` 상황표 ② 어드민 백업·복원 ③ 서버 로그(`docker logs`) ④ 정책 문서 실사고 기록

## 4. 피드백 수집 방법

- 지점 원장 피드백은 노션 데이터 저장소 "원본 데이터"에 날짜별로 그대로 기록(요약·해석은 별도 줄).
- 개발 반영은 GitHub 이슈로 1건 1이슈. 릴리스 노트(`docs/RELEASE-NOTES-CURRENT.md`)에 지점이 읽을 말로 적는다.
- "다시 받아라"는 안내는 절대 하지 않는다(DISTRIBUTION-POLICY). 구버전이면 "닫고 다시 켜세요".
