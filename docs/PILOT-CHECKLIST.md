## 1. 파일럿 시작 전 (본사, 30분)
- [ ] 어드민 대시보드: 파일럿 지점 프로그램 버전이 채널 최신과 같은가 (구버전 배지 없음)
- [ ] 어드민 > 전체 데이터 > 지점 > 백업·복원 탭에 **오늘 날짜 일일 백업**이 있는가
- [ ] 어드민 > 사용자 관리: 계정(원장·직원) 역할·사용기간 확인, 불필요 계정 비활성 — **직원 계정은 매출·설정·직원 관리·고객 삭제·동의 편집·캠페인 관리가 막힌다**(permissions, 결정 #14 가정)
- [ ] 어드민 > 기능 관리: 켜 줄 기능 확정 — `module.aiChat`(AI 챗·브리핑), 비컨, 기타 플래그. AI 모델 카탈로그 배포는 161(`PUT /api/admin/ai/catalog`, 승인 B-2) 뒤 — 지금은 지점 기본 카탈로그
- [ ] 서버 `.env`: `SMS_PROVIDER`(발송사 계약 시 solapi, 승인 C-2), `AI_OPENAI_API_KEY`/`AI_GEMINI_API_KEY`(본사 AI 중계, C-3), `OPS_ALERT_EMAIL`. 본사 Managed AI(크레딧·라우터)는 161 배포(B-2·C-7) 뒤
- [ ] 지점 PC: 설정 > 백업·보안 > 백신 예외 등록 표시 / 전체 백업 1회 저장 / 앱 잠금(PIN) 켤지 결정
- [ ] 지점 PC: 설정 > 알림 설정 — 재방문 권장 주기, **무료수신거부 080 번호**(광고 발송 전 필수 — 190 부터 대시보드 "시작하기 > 파일럿 준비" 에 미완 표시), 개인정보 보존기간 정책
- [ ] 지점 PC: 설정 > 결제수단 — 매장이 쓰는 결제수단 추가(서버 저장이라 한 PC에서만)
- [ ] 지점 PC: 직원 관리 — 직원별 근무표·휴게·버퍼 입력(예약 폼 경고·빈 시간 안내가 이것을 쓴다), 설정 > 자원(베드·룸)
- [ ] 지점 PC: 문자/카카오 > 자동 발송(캠페인) — **"기본 시나리오 16 추가"** 뒤 매장 문구로 수정, 광고성 시나리오는 수신 동의 고객만 가는 것 확인
- [ ] 지점 PC: AI 서비스 탭 — 이용 방식(본사 중계/직접 키) 확인, "이달 경영 브리핑" 1회 실행해 자료 블록에 고객 실명이 없는지 눈으로 확인

## 2. 첫 주에 지점이 실제로 할 흐름 (관찰 포인트)
1. 로그인 → 고객 등록(개인정보 동의 체크) → 엑셀 일괄 업로드 필요 여부 → 고객 상세 **광고 수신 동의** 기록이 자연스러운지
2. 예약 등록(겹침 경고·빈 시간 제안·근무표 경고·베드 배정) → 당일 완료 처리 → 결제 등록(복합결제) → 매출·이달 지표 카드 반영
3. 시술 기록 + 사진 → 다른 PC에서 같은 사진(NAS 동기) → 회차권 "회차 이력"이 현장 기억과 맞는지
4. 문자 발송 시도 → 발송사 미계약이면 "발송 안 됨(pending)" 표기가 이해되는지. 광고성 토글 켰을 때 (광고)·080 자동 표기와 21~08시 차단 안내가 이해되는지
5. 캠페인 "대상 확인·발송" — 오늘 대상 목록이 현장 감각과 맞는지(예약 전날·재방문 권장·회차권 만료), 승인 발송 흐름이 번거롭지 않은지
6. 대시보드 오늘 할 일·이탈 위험·재방문 리마인더 → 대상 산출이 맞는지, 주기 값 조정 필요 여부
7. AI 챗 "오늘 할 일 브리핑"·"이달 경영 브리핑" — 연락할 고객·빈 시간·전월 대비 변화가 쓸모 있는지, 틀린 숫자가 있는지([확정]/[예측]/[추정] 라벨 확인)
8. 지출 등록·손익계산서·월 마감 잠금 → 월말 세무 전달용으로 충분한지
9. 프로그램을 닫고 다시 켰을 때 업데이트가 조용히 적용되는지(버전 표시)

## 4. 피드백 수집 방법
- 지점 원장 피드백은 노션 데이터 저장소 "원본 데이터"에 날짜별로 그대로 기록(요약·해석은 별도 줄). 고객 PII 는 마스킹된 형태만.
- 개발 반영은 GitHub 이슈 1건 1이슈. 릴리스 노트(`docs/RELEASE-NOTES-CURRENT.md`)에 지점이 읽을 말로.
- "다시 받아라"는 안내는 절대 하지 않는다(DISTRIBUTION-POLICY). 구버전이면 "닫고 다시 켜세요".

## 5. 파일럿 중 절대 하지 않을 것
- 지점 데이터에 직접 SQL 수정(어드민 복원·반출 기능을 쓴다)
- 릴리스 게이트(`release:all`) 우회, 코어 잠금 파일 무단 수정
- 고객 PII 를 노션·이슈·AI 프롬프트에 기록(브리핑은 건수·가명만 — 코드가 강제, 눈으로 1회 확인)
- 실고객 대상 자동 마케팅 발송 개시 전 승인(C-9) 없이 광고성 캠페인 승인 발송
