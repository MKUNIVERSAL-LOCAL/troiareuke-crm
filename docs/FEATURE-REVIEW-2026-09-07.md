# 더마솔루션 CRM 자체 기능 검토 (2026-09-07)

오너 요청: "처음 기획·리서치 대비, 보완할 내부 기능·가동되지 않는 기능·추가할 기능을 자체 검토하고 문제는 수정할 것."
방법: 기획·리서치 문서 16종 정독 → 클라이언트(src/) 전 페이지·라이브러리 실코드 대조 → NAS 서버(server.js 52라우트) 대조. 근거는 file:line.

## 0. 한 줄 결론

베이스 레이어(고객·예약·시술·매출·직원·제품·지출·사진·공지·본사 기능관리·자동 업데이트)는 **전부 가동 중**이고 NAS에 정본이 저장된다.
기획의 **3대 킬러 기능은 코드만 있고 실사용 상태가 아니다** — ①AI 피부진단은 기기 토글 기본 OFF + 사용자 키 입력 필요, ②Before/After 타임랩스는 정렬 가이드·공유 없이 뷰어만, ③재방문 리마인더는 대상 산출·초안 복사까지만이고 자동 발송은 서버 스위치 OFF + 발송사 미계약.
외부 계약 게이트(알림톡/SMS 발송사, PG 실개통, 네이버 예약 파트너 승인)가 풀리지 않으면 코드로 더 할 수 있는 것이 없다.

## 2. 가동 현황 요약 (클라이언트)

**✅ 가동**: 고객·프로그램·예약·시술기록/사진·직원·제품·매출/손익/지출·대시보드·설정·온보딩·엑셀/PDF 내보내기·오프라인 아웃박스·공지 배너/게시판·본사 기능관리·무인 자동 업데이트·지점 버전 텔레메트리.

**⚠️ 조건부**: 수동 문자/카카오 발송(서버 `SMS_PROVIDER` 미설정 → "발송 안 됨(pending)" 정직 표기), 결제 링크(서버 `TOSS_*` 키 필요 → "준비 중"), AI 피부분석(사용자가 OpenAI/Gemini 키 입력 + 기기 토글 `feature_beacon_consultation` ON 필요), Google 캘린더(`VITE_GOOGLE_CLIENT_ID` 없어 비활성), 로컬 백업(Electron 전용).

**⏸ 준비 중(의도적 비활성)**: AI 챗봇(본사 기능관리에서 지점별 ON 가능, 기본 OFF), 자동 알림(생일·미방문 토글 disabled), 카카오 채널/네이버 예약 "연동하기", SMS(엔포+) 테스트 발송, 구독 실결제(`PAYMENT_ENABLED=false`), 회원가입 유료 플랜.

**🧪 로컬 전용(PC 바꾸면 유실)**: AI 키 3종, 커스텀 결제수단, 기기 기능 토글, 재방문 주기 설정, API 가이드 체크 상태, Google 토큰.

## 3. 서버 현황 요약

- 라우트 52개 전부 클라이언트 호출과 정합(깨진 호출 0). 죽은 라우트 3개(`/health`는 운영 검증용으로 유지, `POST /api/auth/reset-password`, `GET /api/photos/:entityKey`)는 향후 모바일 대비로 남김.
- 백그라운드: 예약발송 60초, 리마인더 10분, 백업 10분, 정리 24시간. **백업은 실제로 매일 돌고 있음**(NAS `CRM-BACKUP/troiareuke-crm/{지점}_{id}/`, 9월 133파일 확인). 리마인더는 `REMINDER_ENABLED=false`(기본)라 미가동 — 발송사 없으면 켜도 의미 없음.
- `/api/admin/*` 13개 전부 슈퍼어드민 검사 있음. 데이터 컬렉션 허용목록 15종 = 클라이언트 동기 목록 15종 정확히 일치.
- 사진은 `crm_photos`에 base64 JSONB(장당 7MB·엔티티당 100장) — DB 팽창 경로, 파일 스토리지 전환은 중기 과제.
