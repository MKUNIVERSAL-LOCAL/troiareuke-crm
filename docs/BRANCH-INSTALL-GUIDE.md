# 지점 설치·업데이트 안내 카드 (오너·본사용, 2026-09-04)

> 이 문서 하나만 보면 됩니다. "누가 다시 받아야 하나요?"라는 질문에 헤매지 않기 위한 카드입니다.
> 원칙: **설치는 PC당 평생 1회. 그 뒤 모든 변경은 프로그램이 스스로 업데이트한다.** (docs/DISTRIBUTION-POLICY.md)

## 1. 보낼 주소는 하나뿐

```
https://crm-update.mkcorp.familyds.com/
```

- 어드민 콘솔 > 대시보드 > **신규 PC 설치 안내** 카드에서 [주소 복사] / [카톡·문자용 안내 문구 복사] 버튼으로 바로 복사할 수 있다.
- 파일(exe·zip)을 카톡·메일로 직접 보내지 않는다. 구버전 파일이 돌아다니는 원인이다.
- 옛 주소(`/트로이아르케 CRM.exe`, `/latest.json`)는 현재 7월 구버전이 걸려 있다. `scripts/nas-tasks/README.md`의
  "채널 루트 정리" 명령을 NAS에서 1회 실행하면 최신판으로 연결된다 (그 전까지는 위 배포 사이트 주소만 안내).

## 2. 상황별 대응 — 재다운로드는 마지막 수단

| 지점이 말하는 상황 | 먼저 할 일 | 재다운로드? |
|---|---|---|
| "새 기능이 안 보여요" / "버전이 낮아요" | 어드민 대시보드 **지점 프로그램 버전** 확인 → 구버전이면 "프로그램을 완전히 닫고 다시 켜 주세요" (닫을 때 자동 적용) | ❌ |
| "업데이트 배너가 계속 떠요" | 그냥 [지금 재시작] 누르라고 안내. 안 눌러도 닫을 때 적용됨 | ❌ |
| "프로그램이 안 켜져요" | ① 작업 관리자에서 남은 프로세스 종료 → 재실행 ② PC 재부팅 ③ 그래도 안 되면 `%APPDATA%\트로이아르케 CRM\updater.log` 마지막 줄을 받아 개발자에게 전달 | ❌ (진단 먼저) |
| "PC를 새로 샀어요" / "포맷했어요" | 위 주소에서 신규 설치 — 이것만 정상적인 '다시 받기'다. 데이터는 NAS 계정에 있으니 로그인하면 복원 | ✅ (신규 설치) |
| "백신이 파일을 지웠어요" | 백신 예외 등록 후 위 주소에서 설치. 발생 사실을 DISTRIBUTION-POLICY '실사고'에 기록 | ✅ (원인 기록 필수) |

재다운로드가 실제로 필요했다면 **원인을 docs/DISTRIBUTION-POLICY.md 실사고 목록에 추가**한다. 같은 원인은 두 번 발생하면 안 된다.

## 3. 릴리스 뒤 본사가 확인할 것 (48시간 이내)

1. 어드민 대시보드 > 지점 프로그램 버전 → **구버전 지점 0곳** 인지 확인.
2. 구버전으로 남은 지점이 있으면 전화로 "프로그램 닫고 다시 켜 주세요" 한 마디. 그래도 남으면 그 지점 `updater.log`를 받아 원인 파악.
3. "기록 없음" 지점은 v1.0.48 이상이 아직 한 번도 접속하지 않은 곳 — 며칠 두고 다시 본다.

## 4. 어떻게 동작하는가 (한 줄씩)

- 프로그램은 켜진 뒤 5초, 이후 10분마다 배포 서버의 최신 버전을 확인한다.
- 새 버전이 있으면 **직원 조작 없이** 백그라운드로 내려받는다 (작업 방해 없음).
- 내려받은 파일은 **프로그램을 닫을 때** 자동으로 적용된다. 재실행은 하지 않는다 (다음에 켤 때 새 버전).
- [지금 재시작]을 누르면 즉시 적용 + 재실행.
- 적용은 최대 2분 재시도하고 결과를 `updater.log`에 남긴다. 실패하면 다음 실행 때 다시 시도한다.
- 각 지점 프로그램은 서버에 접속할 때마다 자기 버전을 알려준다 → 어드민 콘솔에 표시.
