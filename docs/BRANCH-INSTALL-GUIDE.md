# 지점 설치·업데이트 안내 카드 (오너·본사용, 2026-09-04)

> 이 문서 하나만 보면 됩니다. "누가 다시 받아야 하나요?"라는 질문에 헤매지 않기 위한 카드입니다.
> 원칙: **설치는 PC당 평생 1회. 그 뒤 모든 변경은 프로그램이 스스로 업데이트한다.** (docs/DISTRIBUTION-POLICY.md)

## 1. 보낼 주소는 하나뿐

```
https://crm-update.mkcorp.familyds.com/
```

- 어드민 콘솔 > 대시보드 > **신규 PC 설치 안내** 카드에서 [주소 복사] / [카톡·문자용 안내 문구 복사] 버튼으로 바로 복사할 수 있다.
- 사이트 기본 버튼은 **설치파일**(v1.0.50~, 사용자 폴더 `%LOCALAPPDATA%\Programs\트로이아르케 CRM`에 설치, 바탕화면 '더마솔루션 CRM' 바로가기, 관리자 권한 불필요). 포터블·zip은 대안 버튼. 설치형의 업데이트는 폴더형 zip 경로로 자동 처리된다.
- 파일(exe·zip)을 카톡·메일로 직접 보내지 않는다. 구버전 파일이 돌아다니는 원인이다.
- 옛 주소(`/트로이아르케 CRM.exe`, `/latest.json`)도 2026-09-07부터 최신판으로 연결된다(심링크). 어떤 주소로 받아도 최신이다.

## 2. 상황별 대응 — 재다운로드는 마지막 수단

| 지점이 말하는 상황 | 먼저 할 일 | 재다운로드? |
|---|---|---|
| "새 기능이 안 보여요" / "버전이 낮아요" | 어드민 대시보드 **지점 프로그램 버전** 확인 → 구버전이면 "프로그램을 완전히 닫고 다시 켜 주세요" (닫을 때 자동 적용) | ❌ |
| "업데이트 배너가 계속 떠요" | 그냥 [지금 재시작] 누르라고 안내. 안 눌러도 닫을 때 적용됨 | ❌ |
| "프로그램이 안 켜져요" | ① 작업 관리자에서 남은 프로세스 종료 → 재실행 ② PC 재부팅 ③ 그래도 안 되면 `%APPDATA%\트로이아르케 CRM\updater.log` 마지막 줄을 받아 개발자에게 전달 | ❌ (진단 먼저) |
| "PC를 새로 샀어요" / "포맷했어요" | 위 주소에서 신규 설치 — 이것만 정상적인 '다시 받기'다. 데이터는 NAS 계정에 있으니 로그인하면 복원 | ✅ (신규 설치) |
| "백신이 파일을 지웠어요" | 백신 예외 등록 후 위 주소에서 설치. 발생 사실을 DISTRIBUTION-POLICY '실사고'에 기록 | ✅ (원인 기록 필수) |

재다운로드가 실제로 필요했다면 **원인을 docs/DISTRIBUTION-POLICY.md 실사고 목록에 추가**한다. 같은 원인은 두 번 발생하면 안 된다.

## 2-1. 프로그램 안에서 생기는 문의 (2026-11-25, 223)

재다운로드가 필요 없는 문의입니다. 아래 순서대로 답하면 됩니다.

| 지점이 말하는 상황 | 본사가 할 일 | 매장이 할 일 |
|---|---|---|
| "화면 잠금 PIN을 잊었어요" | 어드민 > 지점에서 그 지점 **[PIN 초기화]**(219). 서버에는 초기화 시각만 올라가고 PIN 자체는 본사도 모른다 | 프로그램을 켜 두면 서버와 통신할 때 PIN 설정이 지워지고 안내가 뜬다 → 설정 > 백업·보안에서 새 PIN을 정한다. (초기화가 아직 안 닿았으면 잠금 화면에서 **로그아웃 → 다시 로그인**으로도 풀린다) |
| "매출 화면이 PIN을 물어요" | 그 매장이 설정에서 그 화면을 고른 것이다(218) | 설정 > 백업·보안 > 앱 잠금 > **PIN을 물을 화면**에서 체크를 해제하면 된다 |
| "프로그램을 켜면 바로 PIN을 물어요" | 전체 잠금이 켜진 상태다 | 같은 자리의 **"자리를 비웠다가 돌아오면 전체 화면을 잠근다"** 를 끄면, 고른 화면에서만 묻는다 |
| "비밀번호를 잊었어요" | 어드민 > 사용자 관리에서 임시 비밀번호 발급 | 로그인 화면 > 비밀번호 재설정 안내를 따라 첫 로그인 때 새 비밀번호를 정한다 |
| "업데이트가 안 돼요" | 어드민 대시보드에서 그 지점 버전을 본다. 채널이 최신인지는 `npm run verify:nas` 로 확인 | 프로그램을 **완전히 종료했다가 다시 켜면** 적용된다(v1.0.48부터 무인 적용). 그래도 안 되면 3절 표로 |
| "백업 파일이 복원되지 않아요" | v1.0.63 이전 파일이면 체크리스트 숨김 결함(195·196) 때문일 수 있다 | v1.0.63 이상으로 업데이트한 뒤 **백업을 한 번 다시 저장**한다. 그 파일은 정상 복원된다 |
| "문자가 안 나가요" | 발송사 연동 상태를 본다(계약 전이면 미연동이 정상) | 발송 이력에 **'미연동'** 으로 남는다 — 가짜 성공이 아니다. 연동 뒤에는 발송 이력에서 **[같은 대상에게 다시 보내기]**(207)로 그 건을 다시 보낸다 |
| "광고 문자가 일부 고객에게 안 갔어요" | 수신 동의·야간(21~8시) 금지가 적용된 것이다 | 고객 상세에서 광고 수신 동의를 확인한다. 동의 없는 고객은 광고 대상에서 빠진다(법 요건) |
| "고객을 지웠는데 발송 이력에 이름이 남아요" | 알려진 제약이다(승인 19 대기). 익명화 확인 창에도 그렇게 적혀 있다(216) | 지금은 남는다. 파기가 필요하면 본사에 알린다 |

> PIN은 **기기마다** 따로다(서버에 올리지 않는다). 한 매장이 PC 두 대를 쓰면 각 PC에서 따로 정한다.

## 3. 릴리스 뒤 본사가 확인할 것 (48시간 이내)

1. 어드민 대시보드 > 지점 프로그램 버전 → **구버전 지점 0곳** 인지 확인.
2. 구버전으로 남은 지점이 있으면 전화로 "프로그램 닫고 다시 켜 주세요" 한 마디. 그래도 남으면 그 지점 `updater.log`를 받아 원인 파악.
3. "기록 없음" 지점은 v1.0.48 이상이 아직 한 번도 접속하지 않은 곳 — 며칠 두고 다시 본다.

## 3-1. 설치 직후 백신 예외 등록 (v1.0.49부터 안내 카드 내장)

미서명 exe라 일부 PC 백신(Windows 보안·V3)이 오탐할 수 있다. 설치 직후 한 번만:

- **프로그램 안**: 설정 → 백업·보안 탭(v1.0.59까지는 '데이터 백업') → **백신·보안 예외 등록** 카드 → 등록할 폴더 2개 표시 + [폴더 경로 복사] + [Windows 보안 예외 설정 화면 열기](경로 자동 복사, `windowsdefender://threatsettings/`). V3 탭에 안랩 메뉴 경로. 완료 후 [등록을 마쳤습니다]로 이 PC에 표시.
- **Windows 보안 수동**: 설정 → 개인 정보 및 보안(Win10: 업데이트 및 보안) → Windows 보안 → 바이러스 및 위협 방지 → 설정 관리 → 제외 추가 또는 제거 → 제외 사항 추가 → 폴더 → 설치 폴더 + `%APPDATA%\트로이아르케 CRM`.
- **V3 Lite/365**: 환경 설정(톱니) → 검사 예외 설정 → 검사 예외 대상 → 폴더 추가 → 같은 두 폴더.
- 배포 사이트 안내 절: https://crm-update.mkcorp.familyds.com/#antivirus (설치 안내 문구에 자동 포함).
- 프로그램이 보안 설정을 **대신 바꾸지는 않는다**(경로 계산·복사·화면 열기까지만). 자동 등록은 백신이 악성 행위로 보는 패턴이라 채택하지 않았다.

## 4. 어떻게 동작하는가 (한 줄씩)

- 프로그램은 켜진 뒤 5초, 이후 10분마다 배포 서버의 최신 버전을 확인한다.
- 새 버전이 있으면 **직원 조작 없이** 백그라운드로 내려받는다 (작업 방해 없음).
- 내려받은 파일은 **프로그램을 닫을 때** 자동으로 적용된다. 재실행은 하지 않는다 (다음에 켤 때 새 버전).
- [지금 재시작]을 누르면 즉시 적용 + 재실행.
- 적용은 최대 2분 재시도하고 결과를 `updater.log`에 남긴다. 실패하면 다음 실행 때 다시 시도한다.
- 각 지점 프로그램은 서버에 접속할 때마다 자기 버전을 알려준다 → 어드민 콘솔에 표시.
