주요 기능

제공 기능

현장에서 쓰는 기능.

고객 관리

피부 타입·등급·방문 이력을 한 장의 고객 카드에. 개인정보 동의 기록도 같은 카드에 남습니다.

예약 관리

주간·일간 캘린더, 직원별 예약 현황. 완료 처리하면 결제가 매출에 바로 잡힙니다.

회원권 · 티켓

10회권·정액권 회차가 시술 기록과 함께 자동 차감. 어떤 관리로 몇 회를 썼는지 고객별로 남습니다.

매출 · 통계

일·월 매출, 결제수단별 집계. 카드+현금 복합 결제와 매장별 커스텀 결제수단을 지원합니다.

시술 기록 · 사진

시술 내용과 Before/After 사진을 고객 카드에 저장. 방문 때 경과를 함께 확인할 수 있습니다.

데이터 보관

모든 기록은 중앙 서버에 저장되고 매일 백업됩니다. PC가 고장 나거나 인터넷이 끊겨도 데이터는 보존됩니다.

도입 문의

이메일로 매장 이름과 연락처를 보내주세요.

계정 발급

매장 전용 계정과 임시 비밀번호를 발급합니다.

설치 후 로그인

설치파일을 더블클릭하면 자동 설치되고 바로 실행됩니다. 계정으로 로그인하면 끝.

다운로드

설치는 한 번

이후 업데이트는 프로그램이 스스로 받아 닫을 때 자동 적용됩니다. 다시 받을 필요 없습니다.

Windows 설치파일

파일을 더블클릭하면 설치되고 바탕화면에 아이콘이 생깁니다. 관리자 권한 불필요.

설치파일 다운로드 (무료)
다운로드 후 Windows가 파란 창(Windows의 PC 보호)으로 차단하면 [추가 정보] → [실행]을 누르세요. 처음 한 번만 나옵니다.

최신 버전 확인 중…

설치 없이 실행

USB·공용 PC처럼 설치가 어려운 경우 단일 실행 파일을 사용하세요. 기능과 자동 업데이트는 동일합니다.

단일 실행 파일(포터블) 다운로드

보안 프로그램이 두 파일을 모두 막으면 폴더형(ZIP)을 받아 압축을 푼 뒤 '트로이아르케 CRM.exe'를 실행하세요. 다운로드가 안 보이면 Ctrl+J를 눌러 브라우저 다운로드 목록에서 [계속]을 눌러주세요.

설치 후 백신 예외 등록 방법 보기 →

백신 예외

백신 예외 등록

일부 PC의 백신이 자동 업데이트 파일을 오탐할 수 있습니다. 설치 직후 아래 중 하나를 한 번만 하면 됩니다.

프로그램 안에서 (권장)

더마솔루션 실행 → 왼쪽 설정 → 데이터 백업 → 백신·보안 예외 등록.
등록할 폴더 2개가 표시되고 [Windows 보안 예외 설정 화면 열기]를 누르면 경로가 복사된 채 Windows 보안 화면이 열립니다. 붙여넣기 두 번.

Windows 보안 수동 등록 (Win 11 / 10)

① 설정 → 개인 정보 및 보안(Windows 10은 업데이트 및 보안) → Windows 보안 → 바이러스 및 위협 방지
② "설정 관리" → 맨 아래 "제외"의 제외 추가 또는 제거 → 관리자 확인 [예]
③ 제외 사항 추가 → 폴더 → 프로그램 폴더와 %APPDATA%\트로이아르케 CRM을 각각 추가

안랩 V3 Lite / V3 365 수동 등록

① V3 창 오른쪽 위 환경 설정(톱니바퀴) → 왼쪽 검사 예외 설정
② "검사 예외 대상"에서 폴더 추가 → 프로그램 폴더와 %APPDATA%\트로이아르케 CRM을 각각 선택 → 확인
③ "실시간 검사 예외" 항목이 따로 있는 버전은 같은 폴더를 한 번 더 추가

처음 실행 때 "Windows의 PC 보호" 파란 창이 뜨면 추가 정보 → 실행. 처음 한 번만 나옵니다. 폴더 경로는 프로그램 안 설정 → 데이터 백업 → 백신·보안 예외 등록에서 복사할 수 있습니다.

자주 묻는 질문

궁금하신 점

계정은 어떻게 만드나요?
자체 가입은 받지 않습니다. 도입 문의를 주시면 매장 전용 계정과 임시 비밀번호를 발급합니다. 첫 로그인 후 비밀번호를 변경하세요.
데이터는 어디에 저장되나요? PC가 고장 나면요?
모든 기록은 중앙 서버에 실시간 저장되고 매일 백업됩니다. PC를 바꾸거나 프로그램을 다시 설치해도 로그인하면 데이터가 그대로 있습니다.
인터넷이 끊기면 입력한 내용이 사라지나요?
아니요. 인터넷이 끊긴 동안 저장한 내용은 PC에 보관되고, 연결이 돌아오면 자동으로 서버에 전송됩니다. 화면 상단에 전송 대기 상태가 표시됩니다.
업데이트할 때마다 다시 설치해야 하나요?
아니요. 새 버전이 나오면 프로그램이 스스로 받아 두고, 닫을 때 자동으로 교체됩니다. 설치 파일을 다시 받을 필요가 없습니다.
비밀번호를 잊어버렸어요.
본사 관리자에게 연락해 주세요. 본인 확인 후 임시 비밀번호를 즉시 발급합니다.
