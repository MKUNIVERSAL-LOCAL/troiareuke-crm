주요 기능

매일 하는 일이 다 들어있습니다

피부관리실 현장에서 실제로 쓰는 기능만, 군더더기 없이.

고객 관리

피부 타입·등급·방문 이력을 한 장의 고객 카드로. 개인정보 동의 기록까지 자동 관리되어 법적 리스크를 줄입니다.

예약 관리

주간·일간 캘린더와 직원별 예약 현황을 한눈에. 완료 처리하면 결제까지 바로 매출에 잡힙니다.

회원권 · 티켓

10회권·정액권 회차가 시술 기록과 함께 자동 차감. 어떤 관리로 몇 회를 썼는지 고객별로 투명하게 남습니다.

매출 · 통계

일·월 매출과 결제수단별 집계를 자동으로. 카드+현금 복합 결제, 매장별 커스텀 결제수단도 지원합니다.

시술 기록 · 사진

시술 내용과 Before/After 사진을 고객 카드에 차곡차곡. 관리 경과를 고객에게 보여주며 재방문을 만듭니다.

데이터 안심 보관

모든 기록은 회사 중앙 서버에 저장되고 매일 백업됩니다. PC가 고장 나도, 인터넷이 끊겨도 데이터는 안전합니다.

도입 절차

오늘 문의하면, 바로 시작합니다

1

도입 문의

이메일로 매장 이름과 연락처를 보내주세요. 본사에서 안내를 드립니다.

2

계정 발급

본사가 매장 전용 계정과 임시 비밀번호를 발급해 드립니다.

3

설치 후 로그인

프로그램을 내려받아 실행하고 로그인하면 끝. 별도 설치 과정이 없습니다.

다운로드

Windows용 프로그램 받기

내려받은 파일을 더블클릭하면 바로 실행됩니다. 설치 마법사 없음.

자주 묻는 질문

궁금하신 점

계정은 어떻게 만드나요?
보안을 위해 자체 가입은 받지 않습니다. 도입 문의를 주시면 본사에서 매장 전용 계정과 임시 비밀번호를 발급해 드리며, 첫 로그인 후 비밀번호를 직접 변경하시면 됩니다.
데이터는 어디에 저장되나요? PC가 고장 나면요?
모든 기록은 회사 중앙 서버에 실시간 저장되고 매일 백업됩니다. PC를 바꾸거나 프로그램을 다시 설치해도 로그인만 하면 데이터가 그대로 있습니다.
인터넷이 끊기면 입력한 내용이 사라지나요?
아니요. 인터넷이 끊긴 동안 저장한 내용은 PC에 안전하게 보관되고, 연결이 돌아오면 자동으로 서버에 전송됩니다. 화면 상단에 전송 대기 상태가 표시됩니다.
업데이트할 때마다 다시 설치해야 하나요?
아니요. 새 버전이 나오면 프로그램 안에 알림이 뜨고, 버튼 한 번이면 자동으로 교체됩니다. 설치 파일을 다시 내려받을 필요가 없습니다.
비밀번호를 잊어버렸어요.
본사 관리자에게 연락해 주세요. 본인 확인 후 임시 비밀번호를 즉시 발급해 드립니다.

지금 도입 문의를 남기시면 계정 발급부터 첫 로그인까지 본사가 함께합니다.
